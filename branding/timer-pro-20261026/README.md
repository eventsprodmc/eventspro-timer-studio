# Timer PRO family icon

Approved EventsPRO Timer pictogram with a yellow frame and transparent outer corners. Files: SVG source, 1024 px PNG and macOS ICNS (16–1024 px).

This branding-only addition does not change the Timer executable, OSC/LAN behavior, stored projects, Companion module package or module version 1.2.0. It is not a new module release, Bitfocus approval, or evidence of availability in the official Companion catalogue.

The physical acceptance test with real Companion, Windows and a phone on a local network without internet remains pending. Existing automated results do not replace that test.

These files alone do not update an installed Mac app. They must be included in a separately verified Mac distribution; preserve the current app and its data before replacement. No Mac installer is included in this commit.
